Solutions

Edge cases and platform quirks that took real debugging time

Solution
PTY Line Endings
Why sending \r\n to a terminal on Windows produces a continuation prompt instead of executing.
 Solution
Venv + Node.js
Pin both the Python interpreter and its output encoding when Node.js shells out — PATH and the OS locale aren't enough.
 Solution
Agent Detection
Detecting when an AI agent is running in a terminal — hooks for accuracy, PTY scanning for resilience.
 Solution
Process Lifecycle
npm start orphans child processes when killed. Run node directly.
 Solution
Silent Bind Degradation
A "best-effort" secondary bind hits a restart race and silently runs loopback-only. Retry the failure you understand; crash on the one you don't.
 Solution
Inherited PWD Leak
A spawned shell inherits PWD from its parent, and a config-walking tool trusts it over the real working directory. Strip it.
 Solution
Cloud Sync Locking
Build tools fail when Dropbox locks files mid-write. Stop sync, build, restart.
 Solution
Windows Shell Quirks
Encoding, paths, null redirection, and other surprises when building agent tools on Windows.
 Solution
Cross-Platform Seams
Where one repo on Windows and macOS clones actually breaks — BSD vs GNU sed flags, machine identity, OS-specific labels.
 Solution
xterm.js Upgrade
Migrating from xterm.js 5.x to 6.x — scrollbar init, double output, and changed scroll APIs.
 Solution
Offline-First Model Serving
Fully cached weights, dead server — an expired auth token in an online validation probe. Local serving must never depend on network validation.
 Solution
Stale Prompt Delivery
A prompt or config fix is in force when the consuming run's checkout contains it — not when you commit it. Verify at the run's own commit before blaming the rule.
 Solution
Transient git EINVAL
Transient Invalid argument writes inside .git/objects under cloud sync — an open ledger, a pre-declared verdict lane, and the probe that tells retry from stop.

Principles

Rules that exist because something went wrong without them

Understand before you fix
A workaround that bypasses a misunderstood problem creates two problems.
Surface errors, don't swallow them
An error you hide is an error you'll hit again later in a worse context.
Prefer simplicity
Premature optimization and premature generalization are the root of all evil.
Push back, don't placate
Agreeing eagerly is not being helpful.
Don't be defensive
The goal is to do the right thing, not to justify what's already been done.
Read fully — directly or by proxy
Delegate full reads to a careful-reader subagent, never a summarizer — a summarizer hides what it dropped.
Synthesize, don't summarize
Focus on novel connections and coherence over exhaustive coverage.
